Why it’s fast

Built like infrastructure, not a demo

Zero-copy serving

sendfile straight from disk to socket. No app-server copies, no database in the hot path.

Immutable caching

/assets/v1/* ships max-age=31536000, immutable. Bump the version to invalidate, never a query string.

7 formats

SVG, WebP, PNG and JPG for the web, plus PDF, AI and EPS masters with Range support.

Accept negotiation

Omit ?format= and the resolver serves WebP to modern browsers, PNG everywhere else.

254 pages pre-rendered

Every country page is statically generated at build time. First paint never waits on an API.

Rate-limit friendly

Generous per-IP token bucket. Exceeding it returns 429 with Retry-After, never a silent drop.

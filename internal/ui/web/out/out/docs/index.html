API reference

One domain, JSON metadata + smart flag resolver + immutable asset URLs. CORS open (*).

Overview

Base URL is wherever you deploy the binary. Every example here uses a relative path — in production it’s https://your-domain serving both the API and this UI.

quickstart
# metadata for Bangladesh
curl /api/v1/countries/bd | jq '{name, capital: .meta.capital}'

# resolve a flag (Accept-negotiated WebP)
curl /api/flags/bd?size=320 --output bd.webp

Endpoints

GET/api/v1/countries?search=&region=Open JSON

List all 254 countries. Optional fuzzy search and region filter (e.g. ?region=Asia).

GET/api/v1/countries/{code}Open JSON

One country. ISO2, ISO3 or numeric code, any case — bd, BGD and 050 all work.

GET/api/v1/countries/{code}/assetsOpen JSON

Every available asset for the country: type, format, size, bytes and canonical URL.

GET/api/v1/assetsOpen JSON

Global manifest: counts, per-format breakdown, image/icon sizes, total bytes.

GET/api/flags/{code} Try it

Smart resolver. Picks the best variant from ?type=&format=&size= (also mounted at /api/v1/flags/{code}).

GET/assets/v1/{…} See assets

Canonical immutable file passthrough. What you put in <img> tags.

GET/healthz · /readyzOpen JSON

Liveness and readiness probes for orchestrators.

Quiz API

Stateless seeded quizzes — same seed+mode+difficulty+count → byte-identical quiz forever. No DB, no sessions. Daily challenge derives the seed from the UTC date.

GET/api/v1/quiz/metaOpen JSON

Modes, difficulties, counts + today's daily block.

GET/api/v1/quiz/questions?mode=&difficulty=&count=&seed= Play

Generate a quiz. Seed optional (u64 or string → FNV-1a). With seed → cacheable 86400s.

GET/api/v1/quiz/dailyOpen JSON

Today's daily (UTC) + full question set in one call.

POST/api/v1/quiz/grade Play

Stateless grade: server regenerates from seed. Body {seed, mode, difficulty, answers[], timesMs[]}; -1 = timeout.

quiz
# seeded quiz (replays identically)
curl "/api/v1/quiz/questions?mode=mixed&difficulty=easy&count=5&seed=42"

# daily
curl /api/v1/quiz/daily | jq '{date, dailyNumber, mode}'

# grade (timesMs per question)
curl -X POST /api/v1/quiz/grade -d '{"seed":"42","mode":"mixed","difficulty":"easy","answers":[0,1,2,3,0],"timesMs":[900,1200,800,1500,2100]}'

Share links carry ?seed= — opening one reproduces the identical quiz on any device. Daily seed = FNV1a64("daily-" + YYYY-MM-DD), Daily #1 = 2025-01-01 UTC.

Resolver params

typeimage (default) or icon. Vector formats imply vector.
formatsvg · webp · png · jpg · pdf · eps · ai. Default: Accept negotiation (webp → png).
sizeN for width (e.g. 320) or WxH (e.g. 80x60). Default 320 image / 64 icon. Exact match → smallest ≥ → largest.
download?download=1 sends Content-Disposition: attachment.
resolver
# exact width, explicit format
curl "/api/flags/jp?type=image&format=png&size=640" -o jp.png

# icon for a favicon pipeline
curl "/api/flags/de?type=icon&size=64" -o de-64.webp

# master download
curl "/api/flags/fr?format=pdf&download=1" -o fr.pdf

Format guide

SVGBest default for vector consumers; infinitely scalable; gzipped on the wire.
WebPPreferred modern raster (25–40% smaller than PNG). Use Accept negotiation or ?format=webp.
PNGCompatibility + transparency fallback; predictable API default.
JPGOnly on explicit request — flat flag colors compress poorly as JPEG.
PDF / AI / EPSMaster downloads; Range-enabled; use ?download=1.

Caching

cache headers
/assets/v1/*        → public, max-age=31536000, immutable   (bump v1 to invalidate)
/api/flags/*        → public, max-age=86400, stale-while-revalidate=604800 + Vary: Accept
/api/v1/countries*  → public, max-age=3600, stale-while-revalidate=86400
ETag: "<size>-<mtimeNano>" · conditional requests → 304 · Range → 206

Because /assets/v1/* is immutable, set a far-future Expires in your CDN and never purge — a data refresh ships as a new version prefix.

Errors

JSON bodies with a machine-readable code, suitable for switch statements:

errors
{"error": {"code": "country_not_found", "message": "..."}}
{"error": {"code": "invalid_format" | "invalid_type" | "invalid_size", "...": "..."}}
{"error": {"code": "variant_not_found", "available_formats": [...], "available_sizes": [...]}}

Rate limits

Generous per-IP token bucket (default 200/min, burst 100). Exceeding it returns 429 with Retry-After. Static assets behind a CDN rarely trip the limiter — back off exponentially and retry.
